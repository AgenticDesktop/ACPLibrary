The module is a thin protocol abstraction built around two interface/implementation pairs:
- `IJsonRpcDispatcher` / `JsonRpcDispatcher`: owns the transport lifecycle (`Connect`, `DisconnectAsync`), wires `MessageReceived` events, deserializes incoming JSON lines into `JsonRpcRequest`/`JsonRpcNotification`/`JsonRpcResponse` via `System.Text.Json`, and dispatches them to concurrently registered handler dictionaries keyed by method name. Outgoing requests are serialized through `JsonOptions.Default` and sent over `_transport.SendAsync`.
- `IRequestTracker` / `RequestTracker`: manages in-flight request/response correlation using a `ConcurrentDictionary<long, TaskCompletionSource<JsonRpcResponse>>` and an `Interlocked.Increment` counter for unique IDs. Responses complete the TCS; errors are wrapped in `JsonRpcException`; `CancelAll` aborts all pending requests on disconnect.

Dependency direction is one-way: `JsonRpcDispatcher` depends on `IRequestTracker` (injected, defaults to `RequestTracker`) and `IAgentTransport`, while `RequestTracker` has no internal dependencies beyond `JsonRpc` types. The transport is abstracted behind `IAgentTransport`, keeping this module transport-agnostic.
