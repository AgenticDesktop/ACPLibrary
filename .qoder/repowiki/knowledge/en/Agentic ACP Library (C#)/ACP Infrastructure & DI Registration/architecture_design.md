Two focused static helpers in the `Agentic.ACPLibrary.Infrastructure` namespace:
- `JsonOptions.cs` exposes a lazily-initialized, thread-safe singleton `JsonSerializerOptions.Default` configured with case-insensitive property matching, null-skip serialization, compact output, out-of-order metadata support, and two custom converters (`JsonRpcMessageConverter`, `JsonStringEnumConverter`).
- `ServiceCollectionExtensions.cs` defines two fluent `IServiceCollection` extensions: `AddAcpClient` registers the HTTP-based ACP client pipeline (dispatcher, request tracker, `AcpClient` as singleton), and `AddAcpAgent<THandler>` registers the stdio-hosted agent pipeline (transport, dispatcher, tracker, handler, `AcpAgent`) with a compile-time generic constraint on `IAcpAgentHandler`. Both follow the standard Microsoft.Extensions.DependencyInjection pattern and are mutually exclusive per process.
Dependency direction is one-way: this module depends on higher-level abstractions (`Agent`, `Client`, `Protocol`, `Transport`) but exposes no implementation details back to them.
