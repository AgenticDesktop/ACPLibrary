模块采用接口+实现的解耦设计，核心由四部分组成：
- `IJsonRpcDispatcher` / `JsonRpcDispatcher`：协议分发入口，负责将方法调用序列化为 JSON-RPC 消息并通过 `IAgentTransport` 发送，同时注册 request/notification 处理器。
- `IRequestTracker` / `RequestTracker`：独立管理待处理请求的生命周期，使用 `ConcurrentDictionary<long, TaskCompletionSource<JsonRpcResponse>>` 按 id 关联请求与响应，支持取消全部挂起请求。
- `JsonRpcException`：封装 JSON-RPC 错误码与消息，在响应包含 Error 时抛出。
- 依赖方向单向向外：依赖 `Agentic.ACPLibrary.Transport`（`IAgentTransport`）和 `Agentic.ACPLibrary.JsonRpc`（消息类型），不反向依赖上层业务逻辑，仅通过委托回调暴露处理器注册点。
