- 所有 I/O 操作均接受 `CancellationToken ct = default` 参数，支持取消语义。
- 可选的 handler 属性默认为 null，未设置时返回统一的 JSON-RPC 错误（如 -32601 且 message 指明功能不可用）。
- JSON-RPC 方法名采用命名空间前缀风格（`session/*`、`fs/*`、`terminal/*`），通过 `_dispatcher.RegisterRequestHandler` / `RegisterNotificationHandler` 动态注册。
- 异步方法统一使用 `Task<T>` 或 `ValueTask` 返回，资源释放通过 `IAsyncDisposable` 的 `DisposeAsync` 封装 `ShutdownAsync`。
- 日志记录使用 `ILogger<AcpClient>`，关键路径（初始化、会话创建、取消、关闭）均输出结构化日志。
