The module is a flat set of immutable C# records (and a few classes) under namespace `Agentic.ACPLibrary.Models`, grouped by concern: session lifecycle messages (`InitializeRequest`, `SessionNewRequest`, `SessionPromptRequest`, `SessionCancelNotification`), streaming updates (`SessionUpdate`, `SessionUpdateWrapper` with a `SessionUpdateParams` wrapper), tooling metadata (`ToolCallInfo`, `Capabilities` with `ClientCapabilities`, `AgentCapabilities`, `PromptCapabilities`, `FileSystemCapability`, `ImplementationInfo`), and content polymorphism (`ContentBlock` with derived `TextContent`, `ImageContent`, `AudioContent`, `ResourceContent`, `ResourceLinkContent`, plus `EmbeddedResource`). Enums live in `Models/Enums/` (`StopReason`, `ToolCallKind`, `ToolCallStatus`) and are shared across multiple model files. All serialization uses `System.Text.Json` attributes (`[JsonPropertyName]`, `[JsonIgnore]`, `[JsonPolymorphic]`, `[JsonDerivedType]`, `[JsonStringEnumConverter]`, `[JsonStringEnumMemberName]`); there is no custom converter or external serializer configuration inside this module. Dependency direction is one-way: models depend only on `System.Text.Json` and each other — they have no runtime logic beyond property getters.
