The module centers on `AcpClient`, the concrete implementation of `IAcpClient`, which owns an `IAgentTransport` and an `IJsonRpcDispatcher` for bidirectional JSON-RPC communication. `InitializeAsync` performs the transport start, connects the dispatcher, subscribes to `session/update` notifications and the agent process exit event, registers built-in request handlers (`session/request_permission`, `fs/read_text_file`, `fs/write_text_file`, and all `terminal/*` methods via `RegisterTerminalHandlers`), then sends the `initialize` handshake and validates protocol version. Session lifecycle is exposed through `CreateSessionAsync`, `LoadSessionAsync`, `SendPromptAsync`, and `CancelSessionAsync`. Outbound capability negotiation declares FS read/write support in `ClientCapabilities`. Handler interfaces (`IPermissionHandler`, `IFileSystemHandler`, `ITerminalHandler`) are injected as nullable properties so the UI layer supplies implementations; when absent, handlers return `-32601` errors or cancel outcomes. Custom extensibility is provided via `RegisterRequestHandler`/`RegisterNotificationHandler` which forward directly to the underlying dispatcher. Dependency direction is inward: `AcpClient` depends on abstractions from `Infrastructure`, `JsonRpc`, `Models`, `Protocol`, and `Transport` namespaces, while no other module imports this one except through the `IAcpClient` contract.
