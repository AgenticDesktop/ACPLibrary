模块以 C# record 定义 JSON-RPC 2.0 的数据契约：`JsonRpcMessage` 为基类（固定 `jsonrpc="2.0"`），派生出 `JsonRpcRequest`（含 id + method）、`JsonRpcNotification`（仅 method，无 id）和 `JsonRpcResponse`（含 id 及 result/error 二选一），错误体由独立的 `JsonRpcError` 表示。所有字段通过 `[JsonPropertyName]` 映射到 JSON 键，可选字段使用 `[JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)]` 控制输出。`JsonRpcMessageConverter` 继承 `JsonConverter<JsonRpcMessage>`，在 Read 阶段根据是否存在 `method`/`id`/`result`/`error` 字段动态反序列化为具体子类，Write 阶段通过模式匹配转发到对应类型的序列化；内部通过缓存的 `JsonSerializerOptions` 移除自身转换器以避免递归。依赖方向单向：转换器依赖各消息类型，消息类型之间仅通过继承关联，无反向依赖。
