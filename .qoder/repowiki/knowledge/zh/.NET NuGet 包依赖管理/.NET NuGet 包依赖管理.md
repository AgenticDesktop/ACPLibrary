该 .NET 标准库使用标准的 NuGet 包管理机制，通过 `.csproj` 文件中的 `PackageReference` 声明第三方依赖，并通过 GitHub Actions 自动化构建和发布 NuGet 包。

**依赖声明方式**
- 所有依赖在 `Agentic.ACPLibrary.csproj` 中通过 `<PackageReference>` 显式声明版本
- 当前依赖包括：Microsoft.Extensions.DependencyInjection.Abstractions (10.0.10)、System.Text.Json (10.0.10)、Microsoft.Extensions.Logging.Abstractions (10.0.10)
- 目标框架为 net10.0，启用 ImplicitUsings 和 Nullable

**包管理与发布流程**
- 使用 GitHub Actions (`nuget.yml`) 进行 CI/CD 流水线
- 支持双源发布：同时推送到 nuget.org 和 GitHub Packages
- 构建时使用 `dotnet pack` 生成 nupkg 包，版本号基于 nightly 后缀
- 通过 NuGet/login@v1 action 获取 API Key，GitHub Packages 使用 Bot Token 认证

**包元数据配置**
- PackageId: ShihaoShen.Agentic.ACPLibrary
- VersionPrefix: 0.1.0
- 包含 README.md 和 LICENSE 文件作为包内容
- 启用 XML 文档生成和 MIT 许可证标识

**约束与限制**
- 未使用 `packages.lock.json` 锁定依赖版本
- 未配置私有 NuGet 源或代理
- 未使用 Directory.Build.props 统一管理多项目依赖
