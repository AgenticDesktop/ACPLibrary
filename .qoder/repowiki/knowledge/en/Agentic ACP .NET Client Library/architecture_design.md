The library is split into four cohesive layers that compose at startup: `models` defines the JSON-serializable ACP data types, `json_rpc` provides the System.Text.Json-based message model and converter, `protocol` implements the JSON-RPC dispatcher and request tracker over an `IAgentTransport`, and `client` exposes the public `AcpClient` that wires transport + dispatcher + handler interfaces (`IPermissionHandler`, `IFileSystemHandler`, `ITerminalHandler`) together. The `.csproj` targets net10.0 and packages the whole assembly as `ShihaoShen.Agentic.ACPLibrary`; consumers build their app by creating a `StdioAgentTransport`, a `JsonRpcDispatcher`, and an `AcpClient`, then assigning handlers before calling `InitializeAsync`. Dependency injection abstractions (`Microsoft.Extensions.DependencyInjection.Abstractions`, `Microsoft.Extensions.Logging.Abstractions`) are used only for logging and optional DI registration, keeping the core dependency-free.
