The root `Agentic.AC CPLibrary.csproj` targets net10.0 and packages all six sub-projects (`models`, `json_rpc`, `protocol`, `client`, `agent`, `infrastructure`) as a single assembly. Layers are strictly ordered by concern: `models` defines immutable JSON-serializable records with `[JsonPropertyName]`; `json_rpc` provides the System.Text.Json converter; `protocol` implements the dispatcher and request tracker over `IAgentTransport`; `client` exposes `AcpClient` wiring transport + dispatcher + pluggable handlers; `agent` is the server-side counterpart routing requests to user code; `infrastructure` registers everything into Microsoft.Extensions.DependencyInjection with shared JSON defaults. Consumers consume a single NuGet feed and build their app by composing `StdioAgentTransport`, `JsonRpcDispatcher`, and `AcpClient`, then assigning handlers before `InitializeAsync`. Dependency injection abstractions are used only for logging and optional registration, keeping the core dependency-free.
