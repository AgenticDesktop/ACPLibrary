Single xUnit project referencing the main Agentic.ACPLibrary via a ProjectReference. Two test classes live at the root of the test project: `AcpClientErrorHandlingTests` exercises the client's public methods (`InitializeAsync`, `CreateSessionAsync`, `LoadSessionAsync`, `SendPromptAsync`) by injecting fake implementations of `IAgentTransport` and `IJsonRpcDispatcher`; `JsonRpcDispatcherTests` validates the dispatcher's behavior using a `CapturingTransport` that records outgoing messages and exposes `RaiseMessageReceivedAsync` to simulate inbound requests. Both tests construct synthetic `JsonRpcResponse` payloads (error or success) to drive assertions without a real agent process.
