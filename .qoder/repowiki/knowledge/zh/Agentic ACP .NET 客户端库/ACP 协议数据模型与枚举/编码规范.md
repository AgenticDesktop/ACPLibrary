- 所有 DTO 使用 `record` 并声明 `init` 只读属性，保证不可变性与 JSON 反序列化兼容。
- JSON 字段名通过 `[JsonPropertyName("snake_case")]` 显式标注，避免默认 PascalCase 映射。
- 可选字段统一使用可空类型（`string?`、`bool?`、`T?`）并配合 `[JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)]` 在序列化时省略空值。
- 多态类型基于 System.Text.Json 的 `[JsonPolymorphic(TypeDiscriminatorPropertyName = ...)]` + `[JsonDerivedType(typeof(...), "tag")]` 声明，且一律启用 `IgnoreUnrecognizedTypeDiscriminators = true` 以向前兼容。
- 枚举统一添加 `[JsonConverter(typeof(JsonStringEnumConverter))]` 并通过 `[JsonStringEnumMemberName("lower_snake_or_camel")]` 指定 JSON 成员名。
