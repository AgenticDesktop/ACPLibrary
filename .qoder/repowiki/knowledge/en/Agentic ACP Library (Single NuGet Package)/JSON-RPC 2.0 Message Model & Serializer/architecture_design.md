The module is a flat set of C# records under the `Agentic.ACPLibrary.JsonRpc` namespace forming a small type hierarchy: `JsonRpcMessage` is the base record with the shared `jsonrpc` field; `JsonRpcRequest`, `JsonRpcNotification`, and `JsonRpcResponse` inherit from it to model the three JSON-RPC 2.0 message shapes. `JsonRpcError` is a sibling record used inside responses. `JsonRpcMessageConverter` extends `JsonConverter<JsonRpcMessage>` and implements polymorphic deserialization by inspecting the raw JSON document for the presence of `method`, `id`, `result`, and `error` properties, then delegating to `JsonSerializer.Deserialize<T>` for the concrete type. The converter caches a derived `JsonSerializerOptions` with itself removed to avoid infinite recursion during nested serialization.
