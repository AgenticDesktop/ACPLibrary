本项目采用 .NET SDK 风格的单项目结构，通过 .csproj 文件定义包元数据、目标框架和依赖项，并使用 GitHub Actions 自动化构建、打包与发布到 NuGet 和 GitHub Packages。

**构建系统与工具链**
- 使用 Microsoft.NET.Sdk（SDK 风格项目），目标框架为 net10.0（.NET 10）。
- 启用隐式 using 和可空引用类型检查（ImplicitUsings=enable、Nullable=enable）。
- 通过 <IsPackable>true</IsPackable> 将库直接打包为 NuGet 包，无需额外 MSBuild 脚本或 Makefile。
- 依赖管理完全基于 PackageReference，引入 Microsoft.Extensions.DependencyInjection.Abstractions、System.Text.Json、Microsoft.Extensions.Logging.Abstractions 三个核心包。

**版本与包元数据**
- 版本号通过 <VersionPrefix>0.1.0</VersionPrefix> 定义，CI 中通过 -p:VersionSuffix=nightly.${{ github.sha }} 追加 nightly 后缀生成唯一包标识。
- 包 ID 为 ShihaoShen.Agentic.ACPLibrary，包含作者、描述、标签、许可证（MIT）、仓库地址等完整元数据。
- 文档生成开启（GenerateDocumentationFile=true），XML 注释会随包一起发布。

**CI/CD 流水线（GitHub Actions）**
- 触发条件：推送到 main 分支时自动执行。
- 运行环境：windows-latest，.NET 版本固定为 10.0.x。
- 流程步骤：
  1. 使用 NuGet/login@v1 登录官方 NuGet.org。
  2. 配置 GitHub Packages 源（使用 Bot Token 认证）。
  3. dotnet pack 以 Release 配置打包，输出到 ./nupkg 目录。
  4. 同时推送到 NuGet.org 和 GitHub Packages 两个源。
- 权限：需要 id-token: write 用于 OIDC 令牌签名推送。

**产物与输出**
- 构建产物位于 bin/（Debug/Release/x64）和 obj/ 目录。
- 打包后的 .nupkg 文件存放在根目录 nupkg/ 下，示例文件名为 ShihaoShen.Agentic.ACPLibrary.0.1.0-test.nupkg。
- README.md 和 LICENSE 作为附加文件打包进 NuGet 包。

**开发者约定**
- 修改版本号需更新 .csproj 中的 <VersionPrefix>。
- 新增依赖通过 PackageReference 添加，避免手动编辑 packages.config。
- CI 仅从 main 分支触发，不支持 PR 构建或测试阶段，本地需自行验证构建。
