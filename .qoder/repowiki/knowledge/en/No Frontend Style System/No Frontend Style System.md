This repository is a pure .NET NuGet library implementing the Agentic Agent Client Protocol over JSON-RPC 2.0. It contains only C# source code for protocol models, transport, serialization, and client logic — there are no CSS, SCSS, HTML, JavaScript, or any frontend styling files whatsoever. The project is a backend/library package with no UI layer, so the `frontend_style` category does not apply.
