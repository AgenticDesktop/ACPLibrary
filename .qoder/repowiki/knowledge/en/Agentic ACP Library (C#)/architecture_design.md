The root project is a single packable .NET assembly (`ShihaoShen.Agentic.ACPLibrary`) that composes six cohesive sub-projects layered by concern: `models` defines the JSON-serializable ACP data types, `json_rpc` provides the System.Text.Json message model and converter, `protocol` implements the JSON-RPC dispatcher and request tracker over an `IAgentTransport`, `client` exposes the public `AcpClient` wiring transport + dispatcher + pluggable handlers (`IPermissionHandler`, `IFileSystemHandler`, `ITerminalHandler`), `agent` provides the server-side counterpart that routes incoming requests to user code, and `infrastructure` registers everything into Microsoft.Extensions.DependencyInjection with shared JSON serialization defaults. The `.csproj` at the root targets net10.0 and packages the whole solution as one NuGet feed; consumers build their app by creating a `StdioAgentTransport`, a `JsonRpcDispatcher`, and an `AcpClient`, then assigning handlers before calling `InitializeAsync`. Dependency injection abstractions are used only for logging and optional DI registration, keeping the core dependency-free.
